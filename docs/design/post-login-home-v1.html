Route and layout

  • Route: /home. Signed-in visits to / redirect here.
  • Desktop: 232px sidebar, main grid 1.65fr / 1fr, 20px gaps, 24px padding.
  • Phone (<760px): one column, bottom tab bar, 16px padding, search moves behind an icon.
  • Light first; every color uses the tokens in globals.css.

Color and type rules

  • Cobalt only for progress: route fill, current step, Mark done, active nav.
  • Red, amber, green only for gap status and the readiness bar. Verified certifications use green because they are a met check.
  • Bricolage Grotesque for headings, Geist for text, Geist Mono for labels and counts. Lucide icons at stroke 1.75.

Privacy

  • Profiles start Private and hidden from search.
  • Phone, email, salary and notice period never appear on public views.
  • Resume quotes render on this page only; they never go into logs or analytics.
  • Settings carries Download my data and Delete my account.

Built from the vision map, the platform plan (accounts to network) and design concept v1. Source: careermetro/post-login-home-v1.html in the project files.
